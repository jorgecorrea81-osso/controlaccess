# Flutter → API en Vercel (HTTP)

1. Despliega el monorepo en Vercel (web + `/api`)
2. Desactiva Deployment Protection en Production
3. En la app usa la URL de Vercel, ej:  
   `https://controlaccess33-git-main-jorge-d006.vercel.app`
4. Instala el APK e inicia GPS

Endpoints:
- `POST /api/devices/register`
- `POST /api/devices/location`
